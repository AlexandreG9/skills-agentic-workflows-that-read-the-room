## Recent updates worth watching

From the [GitHub Changelog](https://github.blog/changelog/) (November 2026):

- **pull_request_target blocked by default on December 2** (Nov 2): review any workflows that rely on it before the change lands.
- **New pull request overview page in public preview** (Nov 5): a fresh way to scan a PR at a glance.
- **A more informative GitHub dashboard** (Nov 10): your home page surfaces more useful context.
- **Secret scanning now detects secrets in GitHub Actions workflow logs** (Nov 9): leaked tokens in logs are easier to catch.
- **Dependabot alerts will pause on inactive repositories** (Nov 10) and **Dependabot version updates support Agent Package Manager** (Nov 3).
- **GitHub Copilot is now available in Xcode and JetBrains Air** (Nov 3-4), extending Copilot to more IDEs.

## Automation ideas from Awesome Copilot

The [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/) collection (published in the [github/awesome-copilot repository](https://github.com/github/awesome-copilot/tree/main/workflows)) includes agentic workflow samples you can adapt:

- `daily-issues-report`: a daily summary of repository issues.
- `ospo-org-health`, `ospo-stale-repos`, `ospo-contributors-report`, and `ospo-release-compliance-checker`: open source program office reporting.
- `relevance-check` and `relevance-summary`: keep content relevant and summarized.
- `weekly-comment-sync`: a weekly comment synchronization routine.
